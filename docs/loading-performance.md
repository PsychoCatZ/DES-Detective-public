# Ускорение загрузки DES Detective

23 ноября 2026. Владелец проверил ускоренную локальную версию, подтвердил скорость и поручил выкладку через DES Control Center. Затем подтвердил отображение на настоящем телефоне в вертикальной и горизонтальной ориентациях, включая ввод с открытой экранной клавиатурой; телефонная проверка выполнялась без Luna. На десктопе отдельно показана работа с Luna. Эти проверки не смешиваются.

## Причина и исправление

Первый разговор загружал лист портретов и пять полных PNG-комнат ради лицевой мимики. В опубликованной на момент диагностики версии изображения имели Cache-Control: no-store. Мастерская и первый разговор передавали 16 884 749 байт изображений.

Подготовлены 31 WebP вместо рабочих PNG: сцены, портреты, снимок-улика и маленькие участки лица. Разрешение комнат и портретных листов сохранено, лицевые участки совмещены с исходными масками. Все исходные PNG оставлены. Полный рабочий набор изображений уменьшен с 73 225 111 до 3 948 676 байт — это объём набора, не обязательная загрузка всего при старте. Изображения выражений запрашиваются только по необходимости.

Имя каждого WebP содержит хеш содержимого. Только строго заданные пути этих файлов получают Content-Type: image/webp и Cache-Control: public, max-age=31536000, immutable. При изменении файла меняется URL. HTML/JS/CSS, прежние PNG и API остаются no-store. Сюжет, сохранения, знания персонажей и модельные запросы не меняются.

## Замер

Локальный Chrome, viewport 390×844, CDP-ограничение 1,6 Мбит/с и 150 ms, чистый контекст для каждого варианта. Это не замер телефона пользователя или VPS в Праге.

| Показатель | До | После |
|---|---:|---:|
| Первая сцена полностью загружена/декодирована от навигации | 16,07 s | 4,67 s |
| Изображения мастерской и первого разговора | 16,88 MB | 0,74 MB |
| Загрузка ресурса портретного листа | 71,53 s | 1,76 s |
| Все ресурсы первого разговора и network idle | 72,10 s | 8,55 s |

Старая загрузка портретов конкурировала с пятью полными сценами. При повторной навигации новый файл сцены имел transferSize=0, то есть взят из кэша. Цифры не являются гарантией для другой сети. Сырые результаты: loading-measurements.json. Полный Lighthouse/Core Web Vitals audit не выполнялся.

## Проверки и выпуск

- quality.cjs — PASS.
- Рабочий серверный выпуск: 26 server/client/air/restart/static-images тестов PASS, включая закрытый эфир после перезапуска и блокировку старой вкладки. Эти air-тесты относятся к рабочему выпуску, не к исторической серверной реализации публичной копии.
- 182 браузерные проверки мимики/интерфейса и 48 мобильных проверок — PASS.
- Совмещение маленьких лицевых слоёв всех четверых — PASS, точность центров до 1 px; внешний вид просмотрен.
- Новая статическая раздача всех 31 WebP, MIME, cache, HEAD и закрытие служебных путей проверяются в tests/static-images.cjs и включены в CI.
- Для автоматических проверок использовались подставные ответы Luna; живая модель не вызывалась.

Публичная копия сохраняет свою историческую серверную структуру: добавлена только раздача WebP и кэширование. Не заменять ей действующую production-службу целиком. Для размещения нужен актуальный сервер с разрешённой раздачей новых файлов; старые PNG не удалять, поскольку на них ссылаются старые вкладки. Источником runtime-адресов является встроенная таблица в index.html. assets/optimized/manifest.json хранит метаданные сборки и намеренно не разрешён публичной статической allowlist.
